Batasan Sistem Saat Ini

Dokumen ini mencatat fitur yang belum aktif penuh atau masih bersifat prototipe. Informasi ini penting untuk mengelola ekspektasi pengguna.
  • Final Submission Mahasiswa: Route dan controller sudah aktif, tetapi visibilitas menu tetap bergantung pada fase dan status dokumen.
  • Ekspor Skripsi: Kaprodi dapat mengekspor CSV. Rekap PDF global belum menjadi fitur tersendiri.
  • Library: Skripsi yang berstatus selesai dan memiliki dokumen final muncul otomatis di library publik. Belum ada workflow kurasi/publish terpisah.
  • Phase Board & Keputusan Akhir: Monitoring tersedia, tetapi automation lanjutan di luar lifecycle utama masih ditunda.
  • Faculty Admin: Role admin masih reserved dan belum diberi kewenangan fakultas. Superadmin teknis sudah aktif dan terpisah dari kewenangan akademik.
  • Workflow per Program Studi: Konfigurasi fase berbeda antar prodi belum tersedia.
  • API / Token Auth: Google login sudah aktif, tetapi layer API/mobile token auth belum menjadi jalur aktif.
  • Google re-auth dan upload logo: File logo tidak diputar ulang setelah sesi re-auth kedaluwarsa; pilih kembali file setelah kembali ke halaman pengaturan.
